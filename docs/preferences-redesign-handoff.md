# Preferences redesign — replaced

This hand-off (the v2 redesign, pull request #1380, 2026-10-18) is replaced by the full-window Settings.

- Plan and decisions: [`docs/pocket/spec/2026-11-25-settings-full-window/plan.md`](pocket/spec/2026-11-25-settings-full-window/plan.md)
- Design source: the Paper file "Termul Design System", page "Troupe - Preference/Settings", boards 1.1–1.11b.
- Rules for settings parts: [`docs/design/forms.md`](design/forms.md) and [`docs/design/overlays.md`](design/overlays.md).

The v2 sitemap (14 pages in 4 groups) is gone. Settings now has 11 pages: Preferences, Terminal, Profiles, Accounts, Agents, Sub-agents, Skills, MCP servers, Browser, Keyboard shortcuts and About. Old page ids (interface, notifications, editor, appearance, shell, updates, server, diagnostics, reset) still open the new page that holds their settings.
