name: Rune

# Builds and tests the apps/rune workspace and renders the `hello` window
# headless on Linux, macOS and Windows, uploading each `hello --snap` PNG as an
# artifact. On Linux it also opens `hello` under Xvfb and drives the real
# window through the live driver (scripts/rune/drive-hello.sh), and snapshots one
# scene of the design-system gallery. A wasm job builds hello and the gallery for
# wasm32-unknown-unknown, and the Troupe shell (troupe-dev natively, troupe-web
# as a web bundle).
# check-pin keeps the `rune` dependency and the six [patch.crates-io] revs in
# apps/rune/Cargo.toml equal to apps/rune/rune.pin. Linux draws through Mesa's
# lavapipe Vulkan driver, Windows through WARP and macOS through a virtual
# Metal adapter — the runners have no GPU.
