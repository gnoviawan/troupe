App settings apply to every project. Open them with `Ctrl+,` (`Cmd+,` on macOS, `Alt+,` in the browser version) or the **Settings** button at the bottom left of the sidebar. Troupe saves each change as soon as you make it.

Settings fills the whole window. The left side has **Back to app**, **Search settings**, and the pages. To close Settings, select **Back to app** or press `Esc`.

![Settings in the full window, with the list of pages on the left](/screenshots/settings-app-preferences.png)

## Preferences

![The Preferences page with the Appearance, Notifications, Links, Editor, and New projects groups](/screenshots/settings-behavior.png)

### Appearance

- **Theme** shows the color theme you use. Select **Change theme** to pick another one. See [Themes](/docs/settings/themes).
- **Interface zoom** makes the whole window bigger or smaller, from 50% to 300%. Select **Reset to 100%** to go back. You can also press `Ctrl+=`, `Ctrl+-`, and `Ctrl+0`. In the browser version these keys belong to the browser, so Troupe uses `Alt+=`, `Alt+-`, and `Alt+0`. When a browser tab is the active tab, the keys zoom only that web page instead. See [Zoom a page](/docs/browser/browser-tabs#zoom-a-page).
- **Translucent sidebar** shows the desktop through the project sidebar, like Finder. Chats, terminals, and editors stay solid. It is off by default. This switch is in the desktop app on macOS only.

### Notifications

Three switches for agent notifications. See [Notifications](/docs/settings/notifications).

### Links

<Callout type="info">This works in the desktop app only.</Callout>

**Open links in** decides where a link opens. It applies to links in chats, terminals, Markdown, and files. In a terminal, `Ctrl+click` the link (`Cmd+click` on macOS).

- **Default browser** opens the link in your system browser. This is the default.
- **Troupe browser** opens the link in a browser tab inside Troupe.

### Editor

**Auto save** saves files in the editor after you stop typing. It is **Off** by default. To turn it on, choose how long Troupe waits after your last edit: **After 0.5 seconds**, **After 1 second**, **After 2 seconds**, or **After 5 seconds**. When you turn it on, files with unsaved changes save immediately.

### New projects

**Default color** is the color that new projects get. You can change the color of one project later in its project settings.

## Terminal

### Text

- **Font size** sets the size of terminal text, from 10 to 24 pixels. The default is 14.
- The preview below it shows sample terminal text at the font size you picked.

### New terminals

- **Default shell** picks the shell that new terminals start. **System default** uses your computer's default shell. The list also shows every shell Troupe found on your computer. A project can use a different shell. See [Project settings](/docs/settings/project-settings).
- **Screen reader mode** lets screen readers read terminal output. It is off by default. In some setups it can repeat the characters you type.

### Advanced

Click **Advanced** to see these options:

- **Renderer** chooses how terminals draw text. **Auto** uses **WebGL**, which draws with your graphics card, and falls back to **DOM** when WebGL is not available.
- **Scrollback** sets how many lines each terminal keeps for scrolling back, from 1,000 to 50,000. The default is 10,000. More lines use more memory.
- **Automatic completion refresh** updates command suggestions while you type. When it is off, press `Tab` to ask for suggestions. It is on by default.

The renderer, scrollback, and screen reader options apply to terminals you open after the change. **Automatic completion refresh** applies immediately.

## Profiles

A terminal profile is a saved way to open a terminal: a shell, its arguments, a start folder, and environment variables.

1. Select **Add profile**.
2. Fill in the fields. Leave a field empty to use what a normal new terminal uses.
   - **Name** is the name you see in the command palette.
   - **Shell** is the shell to run. Choose **Other path or name** to type a shell that is not in the list.
   - **Arguments** go to the shell. Put one argument on each line.
   - **Start folder** is where the terminal opens. Empty means the open project or worktree folder.
   - **Environment variables** are `KEY=value` lines. They replace project variables with the same name.
3. Select **Save profile**.

To open a terminal from a profile, press `Ctrl+K` and choose **New Terminal:** followed by the profile name. Use the pencil button to edit a profile and the trash button to delete it.

<Callout type="warn">Troupe saves profile variables as plain text with your settings. Do not put passwords or API keys in a profile.</Callout>

## Accounts, Agents, Sub-agents, Skills, and MCP servers

These pages set up the agents you chat with. [Agent setup](/docs/agent-setup) explains each one.

- **Accounts** adds Claude, Codex, and Antigravity accounts, picks the default account, and shows how much of each account's limits you have used.
- **Agents** lists the agents Troupe can start and shows whether each is ready. Below the list, **Chats** has **Close idle chats after** and **Suggest automations from repeated chats**. The second one turns [automation suggestions](/docs/automations#suggestions-from-repeated-asks) on or off. **Advanced: time limits** holds the time limits for answers and for starting chats. See [Timeouts and idle chats](/docs/agent-setup/timeouts).
- **Sub-agents** sets whether agents may [start your other agents](/docs/agents/start-other-agents) and how many at a time. Its profiles give each agent a model and thinking level from the message box's model picker, a mode, approvals, and a **When to use** note that tells the agent what each profile is good at.
- **Skills** shows the skills in your home folder and in the open project.
- **MCP servers** manages the tool servers that new agent chats can use, and lets you browse the MCP catalog.

## Browser

The **Browser** page sets what agents may do in the agent browser in every project. **Ask first** sets whether to ask before an agent opens a new site or submits a password. **Pre-approved actions in every project** lists actions that do not need a question. **Logins** has the shared agent profile and the **Clear agent profile** button. Changes save as you make them. See [Let an agent use the browser](/docs/browser/agent-browser#browser-rules).

## Keyboard shortcuts

Change any shortcut in the list. See [Keyboard shortcuts](/docs/settings/keyboard-shortcuts).

## About

The **About** page is different in the desktop app and in the browser version.

### In the desktop app

- The version card at the top shows **Troupe** and your version. Its button checks for updates, downloads an update, and installs it: **Check for updates**, **Download**, and **Install and restart**.
- **Updates** has **Release channel** (**Stable** or **Nightly**) and **Check for updates automatically**. See [Updates](/docs/settings/updates).
- **Logs and bug reports** has **Report a bug** and **Application log**. See [Logs and bug reports](#logs-and-bug-reports).
- **Reset all settings** is at the bottom. See [Reset settings](#reset-settings).

### In the browser version

<Callout type="info">The **Server** group shows only when Troupe is served by `troupe-server`.</Callout>

- The first row shows `termul-server` and the server's version. The browser version updates together with the server. Reload the page after the server updates.
- **Server** changes how the server itself runs: its bind host and port, sessions directory, projects file, whether other devices can make changes, and its update channel. It is the same form as the setup wizard shown on a fresh install. Applying saves the settings to `server-config.json` in the server's state folder and restarts the server. If the address changes, your browser follows the server to the new address by itself. See [Install and start troupe-server](/docs/remote/server#set-it-up-in-the-browser).
- **Logs and bug reports** and **Reset all settings** are the same as in the desktop app, with fewer log buttons.

### Logs and bug reports

Troupe writes a log file that helps find the cause of a problem. This group gets the log out of the app.

![The Logs and bug reports group on the About page, with the Copy button](/screenshots/settings-diagnostics.png)

- **Report a bug**: select **Report** to open the **Report a bug** window. It adds a redacted diagnostics bundle to the report.
- **Application log** has these buttons:
  - **Copy** copies the log to your clipboard. Paste it into a bug report.
  - **Export** opens a menu. **Save as…** saves a copy of the log where you choose. **Save to Downloads** saves a copy named `termul.log` in your Downloads folder. Desktop app only.
  - **Show in Finder** opens the folder with the log file. On Windows the button is **Show in File Explorer**. On Linux it is **Show in file manager**. Desktop app only.

In the browser version, the log is on the computer that runs the server, so only **Copy** is available. See [Report a problem](/docs/troubleshooting/report-a-problem).

### Reset settings

Under **Reset all settings**, select **Reset settings**. It puts every app setting and every keyboard shortcut back to its default. It also shows the sidebar again and closes the side panel. Troupe asks you to confirm first. Select **Reset settings** in the **Reset all settings?** dialog. You cannot undo a reset.

A reset keeps your terminal profiles. Delete them on the **Profiles** page if you want them gone.
