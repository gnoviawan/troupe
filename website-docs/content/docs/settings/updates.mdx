<Callout type="info">This works in the desktop app only.</Callout>

The desktop app checks for new versions of Troupe and tells you when one is ready. You choose how new the versions are with a release channel.

The browser version has no update settings. It updates together with the server, so reload the page after the server updates. To update the server, see [Browser and phone](/docs/remote).

## Open the update settings

1. Open app settings with `Ctrl+,` (`Cmd+,` on macOS).
2. Select **About**.

The version card is at the top of the page. It shows **Troupe** and the version number. Below them, it shows when Troupe last checked, for example **Up to date**, or **Not checked yet**. The update button is at the right of the card. The **Updates** group is below the card.

## Pick a release channel

Under **Updates**, select one of these in **Release channel**:

- **Stable** gets the tested releases. It is the default and the most reliable channel.
- **Nightly** gets a build made every night from the newest code. It can be unstable.

On both channels, Troupe downloads and installs signed updates in the app. On Nightly the page says **Updates are signed and install in the app.**

Troupe used to have an **Insider** channel for release candidates. It no longer exists. If you picked Insider before, Troupe now uses Stable.

If Troupe cannot get a signed update on either channel, for example because there is no network or no build for your system yet, it falls back to the release page. The version card then says **Automatic update is not available. Download and install it from the release page.** Select **Open download page** to open it.

When you switch channels, Troupe clears an update it found on the old channel. Select **Check for updates** to look on the new one.

If you installed Troupe from the AUR on Arch Linux, there is no channel choice. Update with `yay -S troupe`. Before 0.5.0 the package was called `termul-manager`.

## Check for updates

Select **Check for updates** on the version card. If a new version is out, the card shows **Version** and the number, followed by **is available.** The button then changes to **Download**.

On macOS you can also use **Help** > **Check for Updates...** in the menu bar, or press `Cmd+Shift+U`.

If a check, download, or install fails, the version card says which step failed: **Could not check**, **Download failed**, or **Install failed**. Select **Try again** to repeat that step.

## Turn automatic checks on or off

**Check for updates automatically** is in the **Updates** group. It is on by default. Troupe then checks when it starts and again about every 12 hours. Turn it off to check only when you select **Check for updates**.

An automatic check does not undo a download. If Troupe already downloaded a version and the check finds the same one, it stays ready to install.

## Install an update

When Troupe finds a new version, a message appears in the corner of the window: **Update available**, with the version number below it. On Nightly, the message says **Nightly update available**.

1. Select **Download**. If the message offers **Open download page** instead, Troupe opens the release page and you install the new version yourself.
2. Wait for the download. A message shows its progress and goes away when the download ends.
3. When **Update ready to install** appears, select **Install and restart**.
4. Troupe asks you to confirm. Select **Install & Restart**, or **Not now** to install later.

Troupe closes, installs the update, and opens again. Terminals that are running when you install are closed.

To hide the update message for a day, select **Remind me tomorrow**.

You can also install from the version card on the **About** page. Select **Download**. The card shows the progress. When the card says **is downloaded.**, select **Install and restart**.

## See what's new

After an update, the first time Troupe opens it shows a **What's New** window with the release notes of the new version.

- Select **View on GitHub** to read the release page. Troupe shows the address in an **Open external link?** dialog first. Click **Open** to continue. Links inside the release notes ask the same way.
- Select **Got it** to close the window.

The window shows once for each new version.
