If you use Google Antigravity with more than one Google account, for example a personal one and a work one, Troupe can keep them all signed in. Each project uses one account for its Antigravity chats, and one chat can use an account of its own. When a chat's account reaches its quota, Troupe moves that chat to another account.

Accounts apply to the **Google Antigravity** agent from the agent registry. To set up the agent itself, see [Install an agent](/docs/agent-setup/install-agents). For Claude, see [Claude accounts](/docs/agent-setup/claude-accounts). For Codex, see [Codex accounts](/docs/agent-setup/codex-accounts).

## Antigravity needs a Google login

Every Antigravity account is a Google login: a personal Google account, or a Gemini Enterprise account. Troupe does not offer API key accounts for Antigravity, and it does not pass `GEMINI_API_KEY` or `GOOGLE_API_KEY` to the agent when it runs an account Troupe added.

Before an Antigravity chat starts, Troupe checks that the project's account is signed in. If it is not, the chat does not start and Troupe says which login is missing. Sign the account in from **Settings** > **Provider**, as shown below, then try again.

## See your accounts

Open Settings with `Ctrl+,` (`Cmd+,` on macOS) and click **Provider**. The **Antigravity** group lists every account, whether it is signed in, its plan, and which projects use it.

The first account is called **Default**. It is the Antigravity login on this computer. It uses the `.gemini` folder in your home folder (`~/.gemini`), or the folder set by `GEMINI_HOME`. Troupe shows a name you choose for each account, never its email address.

## Add an account and sign in

1. In **Settings** > **Provider**, find the **Antigravity** group and click **Add account**.
2. Type a short name, such as `Work`, and click **Continue**. The account starts signed out.
3. Troupe asks how to sign in. Pick one:
   - **Log in with Google** signs in with a personal Google account.
   - **Log in with Gemini Enterprise** signs in with a work account that has Gemini Enterprise.
4. A sign-in window opens the Google page. Sign in with the account you want to add. When the sign-in finishes, Troupe says the account is signed in.

The sign-in works in the desktop app and in the browser version. If the sign-in does not finish, the account stays in the list, signed out. Click **Sign in** in the account's **⋯** menu to try again.

If the server is read-only for remote clients, the browser version shows your accounts but cannot add, sign in, rename or remove them. Use the desktop app, or a browser that can make changes.

Each account has a **⋯** menu with these actions:

- **Make default**: projects that follow the default use this account. Sign in to the account first.
- **Sign in** or **Sign in again**: repeat the sign-in, for example after the login expires.
- **Rename**: change the name Troupe shows.
- **Remove**: sign Antigravity out of the account on this computer. Its chat history stays. Projects that used it move to the default account, and their open Antigravity chats start again on it. You cannot remove **Default**.

Every account shares the same Antigravity conversations and their artifacts with the Default account, so another account can continue the same chat. When they exist, the hooks, skills and MCP settings in the Default account's `config` folder are shared too. Only the login and the list of trusted folders are separate.

On macOS, Antigravity keeps the Default account's login in the keychain. An account you add keeps its login in a file in its own folder instead, so two accounts never share one keychain entry.

## Choose the account for a project

1. Hover over the project in the sidebar and click its settings button.
2. Click **Accounts**.
3. Under **Antigravity**, pick **Follow default**, or pick one signed-in account.
4. Click **Save changes**.

New Antigravity chats in the project use the account you pick. Open chats that follow the project start again on the new account. Chats that have their own account stay on it.

## Choose the account for one chat

1. In an Antigravity chat, click the account button in the chat box.
2. The menu is called **Account for this chat**. Pick an account, or pick **Follow project** to use the project's account again.

The button shows a pin when the chat has its own account. Picking the account the chat already uses changes nothing. New chats start on the project's account. **Manage accounts** opens **Settings** > **Provider**.

Before a chat starts, the account button in the agent launcher is **Account for this project**. Its first row is **Follow default**.

If the project's environment variables set an absolute `GEMINI_HOME`, Antigravity uses that folder instead of the account you picked.

## Usage and limits

Each account row shows the plan the Antigravity agent reports for that account, for example **Google AI Pro**. The agent names the plan when it starts a chat, so the plan shows after the account's first chat or usage check. Troupe asks for nothing extra to get it.

To see how much quota an account has left, click **Check usage** on its row. Troupe starts the Antigravity agent for that account and runs the agent's own `/usage` command. The row then shows one bar per quota the agent lists, for example **Gemini Models · Weekly Limit Remaining**, and the time of the check. The `/usage` command does not run the model, so a check uses no tokens. When the agent has no quota to report, for example "Not applicable for current authentication method.", the row shows the agent's words instead of bars.

Troupe checks only when you click **Check usage**. It never checks in the background, when you open Settings, on a timer, or when a chat reaches a limit. The bars and the account button in the chat box show the last check until you check again. They clear when Troupe restarts, when you sign in to the account again, and when you remove it. **Check usage** needs a connection that can make changes and a signed-in account.

A check is only for you to read. Troupe never uses it to decide that an account reached its limit, to pick an account for a chat, or to choose when a chat continues.

Each check opens a short session in an empty folder that Troupe owns, never in a project. The Antigravity agent keeps that session in its own session list for the account.

You can also type `/usage` in any Antigravity chat to see the same report there.

Troupe does not read or send the account's Google login. Only the Antigravity agent uses it.

Troupe learns that an account reached its limit from the Antigravity agent. When a chat's turn ends with Antigravity's "Usage Limit Reached" message, Troupe marks that account as limited until the reset time the message gives.

## Switch accounts when you hit a limit

When Antigravity says the chat's account reached its usage limit, a notice at the top of the chat box says so and shows when the limit resets, if Antigravity said when.

In the notice at the limit, you can:

- Click **Switch to** _account_ **and continue**. Troupe moves this chat to that account and continues it with a short message. It does not send your last message again. Troupe suggests the first signed-in account in your list.
- Click **Other account** to pick a different one.
- Click **Continue when it resets** when no other account has room. Troupe continues the chat when the limit resets. Click **Cancel** to stop the wait.
- Click **Add account** to sign in to another account.

### Switch automatically

**Switch accounts automatically** in the **Antigravity** group of **Settings** > **Provider** is on by default. When a chat reaches its account's limit, Troupe moves only that chat to the first signed-in account in your list that has not reached its limit, and continues it with a short message, for example "Troupe moved this chat from Antigravity account Work to Spare because Work reached its usage limit. Continue the task you were working on." Troupe does this on the computer that runs it, so it also works when no window has the chat open. Your last message is not sent again.

When no other account has room, Troupe continues the chat when the limit resets. The notice shows when, for example "Continues at 14:05", on every device that has the chat open. Click **Cancel** to stop the wait. The wait stays in place if you close the app, and it is still there after Troupe starts again.

Turn the switch off to choose yourself in the notice.

## Manage accounts on a server

When Troupe runs as a server for the browser version, the browser can list, add, sign in to, rename, and remove Antigravity accounts, make one the default, and pick one per project. To manage accounts without a browser, run these commands on the server. If the server uses `--state-dir`, add the same `--state-dir PATH` after `antigravity`.

```bash
troupe-server antigravity account list
troupe-server antigravity account add "Work"
troupe-server antigravity account rename <id> "Office"
troupe-server antigravity account default <id>
troupe-server antigravity account project <project-id> <id>
troupe-server antigravity account project <project-id> default
troupe-server antigravity account remove <id>
```

`list` prints each account's ID, name, and whether it is signed in. Antigravity has no sign-in that works in a terminal, so `troupe-server antigravity account login <id>` only tells you to sign in from **Settings** > **Provider** > **Antigravity** in the desktop app or the browser version.

For more about running the server, see [Browser and phone](/docs/remote).
