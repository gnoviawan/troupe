title: Claude accounts
description: Sign in to more than one Claude account, pick one per project or per chat, and watch your limits.

If you have more than one Claude subscription, for example a personal one and a work one, Troupe can keep them all signed in. Each project has an account for its Claude Agent chats, and one chat can use an account of its own. When a chat's account reaches its limit, Troupe tells you and lets you choose what to do next. Before you add more accounts, read [Risks of switching accounts](#risks-of-switching-accounts).

Accounts apply to **Claude Agent** chats only. To set up Claude Agent itself, see [Set up Claude Agent](/docs/agent-setup/install-agents#set-up-claude-agent).

## See your accounts

Open Settings with `Ctrl+,` (`Cmd+,` on macOS) and click **Accounts**. The **Claude Code** group lists every account, whether it is signed in, which projects use it, and how much of its limits it has used.

![The Accounts page, with a Claude Code account named Default that is signed out, and signed-out Codex and Antigravity accounts](/screenshots/agent-setup-provider.png)

The first account is called **Default**. It is the Claude Code login you made with `claude auth login`. Troupe shows a name you choose for each account, never its email address.

## Add an account and sign in

### In the desktop app

1. In **Settings** > **Accounts**, click **Add account**.
2. Type a short name, such as `Work`, and click **Continue**.
3. Your browser opens claude.ai. Sign in with the account you want to add.
4. Go back to Troupe. When the sign-in finishes, Troupe shows the account's plan and usage.
5. Click **Done**, or click **Make default** to use the new account for every project that follows the default.

### In the browser version

The browser can be on another computer or a phone, so Troupe shows you the sign-in link instead of opening a browser on the server.

1. In **Settings** > **Accounts**, click **Add account**.
2. Type a short name, such as `Work`, and click **Continue**.
3. Click **Open sign-in page**. To sign in in another browser or on another device, click **Copy link** and open the link there.
4. Sign in on claude.com with the account you want to add. The Claude page then shows a code.
5. Copy the code, paste it into **Code from the Claude page**, and click **Finish sign-in**.
6. Click **Done**, or click **Make default** to use the new account for every project that follows the default.

If Troupe says the code is incomplete, copy the whole code from the Claude page and paste it again. If Claude does not accept the code, click **Start again** to get a new link.

### If the sign-in does not finish

If you are already signed in to another account on claude.ai, sign out there first, or open the sign-in page in a private window. If the sign-in does not finish, the account stays in the list, signed out. Click **Try again** in the desktop app or **Start again** in the browser version, or click **Sign in** on the account later.

If the server is read-only for remote clients, the browser version shows your accounts but cannot add, sign in, rename or remove them. Use the desktop app, or run `troupe-server claude account` on the host.

Each account has a **⋯** menu with these actions:

- **Make default**: projects that follow the default use this account.
- **Sign in** or **Sign in again**: repeat the sign-in, for example after the login expires.
- **Rename**: change the name Troupe shows.
- **Remove**: sign Claude Code out of the account on this computer. Its chat history stays. Projects that used it move to the default account, and their open Claude Agent chats start again on it. Chats that used it as their own account follow their project again. You cannot remove **Default**.

Every account shares the same Claude Code settings, skills, plugins and chat history. Only the login is separate.

## Choose the account for a project

1. Hover over the project in the sidebar and click its settings button.
2. Click **Accounts**.
3. Pick **Follow default**, or pick one account.

New Claude Agent chats in the project use the account you pick. Open chats that follow the project start again on the new account. Chats that have their own account stay on it.

Before a chat starts, the account button in the agent launcher sets the account for the project too. Its menu is called **Account for this project**, and its first row is **Follow default**.

## Choose the account for one chat

A chat can run on another account than its project, for example to keep a long task on an account with more room.

1. In a Claude Agent chat, click the account button in the chat box. It shows the account's name.
2. The menu is called **Account for this chat**. Pick an account. Each row shows the account's plan and how much of its limits it has used.

Troupe starts this chat again on that account and keeps the conversation. Other chats of the project keep their account. The account button now shows a pin next to the name, and its label says the account is for this chat only.

To go back to the project's account, pick **Follow project** at the top of the menu. The row shows which account the project uses, for example "Uses Work". Picking the account the chat already uses changes nothing. **Manage accounts** opens **Settings** > **Accounts**.

New chats always start on the project's account.

## Watch your usage and limits

Claude plans have a 5-hour limit and weekly limits. In **Settings** > **Accounts**, each account shows how much of its main limit it has used and when the limit resets. Click an account's usage bar to see all of its limits. To read the numbers again, click the refresh button at the right end of the **Claude Code** row.

In a Claude Agent chat, the account button in the chat box shows how much of the 5-hour limit the account has used, for example `5h 42%`. When a weekly limit reaches 80% or more, the button also shows it, for example `5h 42% · Wk 86%`. The number turns yellow at 80% and red at 100%. Open the button to see each account's plan with its 5-hour and weekly use, for example `Max · 5-hour 42% · Weekly 86%`.

Troupe reads these numbers through Claude Code. It never reads your login token. If Troupe cannot read them, the account shows **Usage is not available right now**.

## Switch accounts when you hit a limit

During a chat, Troupe watches the limit of the account the chat uses. When a chat switches accounts, only that chat moves. The other chats of the project keep their account and keep working.

### Near the limit

When the account has used 80% of a limit, a notice at the top of the chat box says how much it has used and when the limit resets, for example "Work has used 85% of its 5-hour limit." You can keep chatting. If another account has room, click **Switch account** and pick one from the list. Click the **×** button to dismiss the notice.

### Switch automatically

**Switch accounts automatically** shows under the accounts in the **Claude Code** group of **Settings** > **Accounts** when you have two or more accounts. It is off by default. If you turned it on in an earlier version of Troupe, it is off after you update, until you turn it on again. When you turn it on, Troupe first shows what the provider's terms say. Click **Turn on anyway** to turn it on, or **Cancel** to leave it off. Read [Risks of switching accounts](#risks-of-switching-accounts) first.

When a chat reaches its account's limit, Troupe moves the chat to the signed-in account with the most room and continues it. Troupe does this on the computer that runs it, so it also works when no app window or browser has the chat open. The chat gets a short message instead of your last message again, for example "Troupe moved this chat from Claude account Work to Spare because Work reached its 5-hour limit. Continue the task you were working on." Subagents and background commands that were running are stopped, and the message asks the agent to start again the ones it still needs.

When no other account has room, Troupe continues the chat when the limit resets. The notice in the chat box shows when, for example "Continues at 14:05", on every device that has the chat open. Click **Cancel** to stop the wait. If you or an automation continue the chat before then, Troupe leaves it alone at the reset.

### Choose yourself

When **Switch accounts automatically** is off, or Troupe could not switch, a notice at the top of the chat box says which limit ran out and when it resets. Your draft is kept.

When another account has room, the notice shows **Go on with** and the account Troupe suggests, the one with the most room left. Click it to pick another account. The list shows each account with its usage bar and how much it has used. The account at its limit is listed last and cannot be picked. Click **Manage accounts** to open **Settings** > **Accounts**. When the account you want is shown, click **Switch and continue**. Troupe moves this chat to that account and continues it with the same short message.

When no other account has room, the notice says "No other account has room left right now." You can:

- Click **Continue when it resets**. Troupe continues the chat when the limit resets and shows when, for example "Continues at 14:05". Click **Cancel** to stop the wait.
- Click **Add account** to sign in to another account.

Project Settings shows the same warning when the project's account is at its limit, with a **Use** button for the account with the most room.

### Worker chats

An agent can start worker chats for parts of a task. When **Switch accounts automatically** is on, each worker chat of a Claude Agent chat runs on its own account: the signed-in account with the most room, unless the agent names one. Troupe moves a worker chat at its limit like any other chat. When the setting is off, worker chats follow the project's account. See [Let an agent start worker chats](/docs/agents/chat-history#let-an-agent-start-worker-chats).

## Risks of switching accounts

More than one account lets you keep, for example, a personal account and a work account apart. A separate work account is fine. Troupe does not recommend that you add many accounts of one provider, or that you use several accounts to get past usage limits.

Anthropic's [legal and compliance page for Claude Code](https://code.claude.com/docs/en/legal-and-compliance) says that plan limits assume ordinary, individual usage of Claude Code and the Agent SDK. The [Consumer Terms](https://www.anthropic.com/legal/consumer-terms) do not allow access to the services through automated or non-human means, except where Anthropic permits it. Anthropic can suspend or end your access without prior notice.

A provider can flag all the accounts of one person and suspend them together. If you often reach your limits, these options are safer:

- Switch by hand: in the notice at the limit, pick an account and click **Switch and continue**, or click **Continue when it resets**.
- Buy extra usage for your Claude plan.
- Use Claude Code with an Anthropic API key, which is billed per use.

## Manage accounts on a server

When Troupe runs as a server for the browser version, the browser can list, add, sign in to, rename, and remove accounts, make one the default, and pick one per project. To manage accounts without a browser, run these commands on the server. If the server uses `--state-dir`, add the same `--state-dir PATH` after `claude`.

```bash
troupe-server claude account list
troupe-server claude account add "Work"
troupe-server claude account login <id>
troupe-server claude account rename <id> "Office"
troupe-server claude account default <id>
troupe-server claude account project <project-id> <id>
troupe-server claude account project <project-id> default
troupe-server claude account remove <id>
```

`list` prints each account's ID, name, and whether it is signed in. `add` prints the `login` command to run next.

To check the server's Claude login and install Claude Agent from the command line, run:

```bash
troupe-server claude auth status
troupe-server claude auth login
troupe-server claude install
```

For more about running the server, see [Browser and phone](/docs/remote).
