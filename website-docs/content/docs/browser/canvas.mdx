title: Edit a design on the canvas
description: Open your project's design file in a tab, edit it, let an agent design on it, and mention its layers in chat.
---

<Callout type="info">The canvas works in the desktop app and in the browser version on a computer. It isn't available on phone-sized screens.</Callout>

The canvas is a design editor inside Troupe. It opens your project's `.figcraft` file, a design file that holds frames, shapes, and text. You can keep the design in the same repository as the code and look at both in one window. The editor is built into Troupe, so you don't need to install anything else.

## Open the canvas

Select a project first. Then use one of these ways:

- Click **Canvas** near the top of the sidebar. When the sidebar is collapsed, click its icon.
- Open the command palette with `Ctrl+K` (`Cmd+K` on macOS), type `canvas`, and run **Open Canvas**.
- Open a `.figcraft` file from the file explorer.


![The command palette filtered to canvas, with Open Canvas at the top](/screenshots/browser-canvas-palette.png)

Troupe opens the first `.figcraft` file in the project's root folder, in alphabetical order. It doesn't look in subfolders. If the project has no `.figcraft` file yet, you start with an empty design, and Troupe saves it as `design.figcraft` in the root folder the first time it saves.

Each project has one canvas tab. If it is already open, Troupe switches to it. When you close the tab, the design stays loaded in the background, so an agent can keep working on it.

## Work in the canvas tab

The bar at the top of the tab shows the file name and the editor's status:

- **Starting canvas…** while the canvas starts.
- **Loading editor…** while the editor loads.
- **Ready** when you can edit.
- **Canvas unavailable** if the editor couldn't open. The reason shows in the tab.
- **Open in another window** if you opened the same design in another Troupe window or browser tab. That window now has it. Click **Take back** to bring it back here.
- **Unloaded** if Troupe unloaded the design to save memory. Troupe keeps two designs loaded at a time. Click **Reopen canvas** to load it again.

Below the bar is the editor. Use its tools to add and change frames, shapes, and text. The editor uses the same light or dark appearance as Troupe. Its header shows the design's file name and the project name.

The editor includes one font, Inter. On Windows, the desktop app also lends the editor a few installed fonts (Segoe UI Symbol, Microsoft YaHei, Malgun Gothic, and Segoe UI Emoji), so symbols, Chinese, Japanese and Korean text, and emoji show up instead of empty boxes. On macOS and Linux, and in the browser version, those characters can still show as empty boxes.

## Save your changes

Troupe saves your changes on its own a moment after you stop editing. A dot next to the file name means there are unsaved changes. To save right away, click **Save** at the right end of the bar. If a save fails, the bar shows **Save failed**.

When Troupe unmounts the canvas, for example when you close a project or quit Troupe, it saves first. If that save fails, Troupe asks what to do: **Retry**, **Keep editing**, or **Discard changes**. Closing the canvas tab does not unmount the canvas, so it doesn't start this save or show these choices.

## When the file changes outside Troupe

If the `.figcraft` file changes on disk while you have no unsaved changes, Troupe loads the new version. If you do have unsaved changes, Troupe pauses saving and asks you to choose:

- **Keep mine** keeps your version.
- **Take disk** drops your changes and loads the version on disk.
- **Save a copy** writes your version to a new file next to the design, named like `design.conflict-20261025-091500.figcraft`, then loads the version on disk.

If the file was deleted, choose **Keep mine** to create it again from your version.

If the editor stops responding, Troupe reloads it from the last save and tells you how many unsaved changes were lost.

## Let an agent design on the canvas

Agents you chat with in Troupe get canvas tools on their own. You don't need to add an MCP server. An agent can read the design, change it, take screenshots of it, and save it. The design must be open on the canvas, or still loaded in the background, for those tools to work. While an agent works, you see its cursor on the canvas with the agent's name.

Troupe also gives agents a set of design guides. They explain how to build a design step by step, how to handle a short request such as "landing page for a bakery", and how to lay out landing pages, web app screens, phone screens, dashboards, slides, social posts, and design systems. The session tells agents to read the guides before their first edit, and the guides work even when no canvas is open.

When you don't name a brand or a look, the agent can pick one of ten ready-made styles, such as **Warm Editorial**, **Clean SaaS**, or **Night Tech**. Each style sets colors for light and dark mode, text sizes, spacing, and corner rounding. The agent tells you which style it picked and why. Every style uses the Inter font, because that is the font the canvas includes.

See [Agent setup](/docs/agent-setup) for how to start a chat with an agent.

## Mention canvas layers in chat

You can point an agent at parts of your design from a chat's message box. While the project's canvas is open, or still loaded in the background, type `@` in a chat in that project. The mention menu then has a **Canvas** entry next to **Conversations** and **Explorer**. Pick it to open its panel:

- **Selection** shows the layers you have selected on the canvas right now. When you select several layers, the entry is named after the first one plus a count, such as `Header +2`.
- Under the page's name, the panel lists the layers at the top level of the current page, with each layer's type and size.

Type to filter the panel by layer name. If nothing matches, the panel says "No layers match. Try another name." An empty page shows "Nothing on this canvas page yet." If Troupe can't read the canvas, the panel shows "Couldn't read the canvas".

Pick a layer or the selection to add it as a pill. The pill keeps the layers you picked, so selecting something else on the canvas later doesn't change it. Press `Backspace` right after a pill to remove the whole pill.

When you send, Troupe reads the mentioned layers from the canvas and gives the agent an outline of each one: its type, name, id, size, position, text, component, and whether it is hidden, plus its children two levels deep. The canvas outlines in one message add up to at most 12,000 characters. If Troupe can't read a layer because the canvas isn't open, the layer isn't found (for example, it was deleted), or the message reached that limit, the agent gets a note that says why instead of the outline. **Retry** reads the layers again. When you open the chat later, your message shows the pills again.

Canvas mentions work the same in the desktop app, on a [shared desktop](/docs/remote/share-desktop) with full control, and in the [browser version](/docs/remote/web-browser). See [Mention a file or another chat](/docs/agents/write-a-prompt#mention-a-file-or-another-chat) for the rest of the mention menu.
